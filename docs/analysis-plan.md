# Execution map

The authority is [the frozen preregistration](https://doi.org/10.5281/zenodo.18828766), particularly §§3.1–3.6. This file describes an implementation path and its gaps, not an amendment.

First, record the exact ds005620 version and hash the input files. Audit event vocabulary and determine independent awakening/response anchors from dataset documentation. Verify one-to-one mapping of BIDS event time to the matching raw recording. Exclude channels and windows using rules fixed before observing outcome contrasts. Define eligible stable-sedation control intervals before computing proxies. Construct a participant/episode manifest with explicit controls, verify all 10 and 30 s windows, and preserve excluded episodes with reasons.

Next, compute *all* required registered families (ρ: wPLI-like, directed VAR; γ: VAR instability, variance transfer; μ: participation ratio, correlation dimension, PCA error slope). Optional transfer entropy and conditional TMS require documented availability/feasibility checks. Store per-window raw proxies, units, QC, preprocessing configuration, software versions, and their relation to preregistration clauses. Keep subject as the independent unit for group inference. Failure or disagreement in μ must be reported according to its two-of-three rule, not repaired by selective estimators.

Criterion A requires subject-consistent pre versus matched-control deviation and multiplicity-corrected group inference. Criterion B tests whether pre/post proxy trajectories fail to retrace after adjusting for total and alpha power. Criterion C compares interaction contribution in near-boundary against controls but still needs a defined dependent variable and numerical meaning of “substantially.” Criterion D is non-gatekeeping and requires a specified identifiable k-like estimand. Run the same locked analysis on both window lengths. A proxy family with qualitative inconsistency between durations is declared uninstrumentable as specified in §3.2. Preserve negative and indeterminate results. The final Gate can be assessed only after these definitions and checks are fixed; the current program never computes it.

Interpretation remains narrower than the original IRC theory: a positive structural screen would warrant pursuing the Stage 2 protocol, not a claim that the EEG measurement proved consciousness instantiation. A negative result requires separate discussion of structural failure and measurement failure; measurement failure cannot be asserted without independent evidence (§3.6).
